# Server 层实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `packages/server`：把已完成的引擎层（`Session`、事件日志）经 HTTP 接口和 SSE 事件流暴露给浏览器，并补上"取消运行中的角色"（backlog B-005）。

**Architecture:** `server` 只依赖 `core`，用 Node 自带的 `node:http` 实现，不引入框架。每个服务进程管理一个项目目录、一个 `Session`；接口是薄层，业务全部在 `core`。`POST /api/message` 立即返回 202，进度和结果走事件流。服务只监听本机，并校验 `Host` 与 `Origin`，防止浏览器里的任意网页向本机服务发请求。

**Tech Stack:** Node.js（ES modules，`node:test`，`node:http`，`fetch`），npm workspaces。不新增任何第三方依赖。

**Spec:** `docs/superpowers/specs/2026-10-30-web-console-design.md`（第 4.2、5、6 节）。前置计划：`docs/superpowers/plans/2026-11-02-engine-layer.md`（已完成）。

## Global Constraints

- 不新增第三方依赖；`packages/server` 只依赖 `@agentteam/core`。
- 服务只能监听 `127.0.0.1`、`localhost`、`::1`。开放远程访问前必须先实现访问令牌（`docs/backlog.md` B-002），本计划不做。
- 所有 `POST`/`PUT` 请求和所有请求的 `Host` 都要通过本机校验（Task 2），否则返回 403。
- API key 只写入凭证文件。不得出现在任何响应、事件、日志或错误信息里；错误信息一律用固定文案，不回显请求内容。
- 请求体上限 64 KB，超出返回 413；`text` 上限 20000 字。
- 同一项目同时只允许一个运行：第二个运行请求返回 409。
- 现有测试保持通过。基线：cli 49、core 98、protocol 7（每个任务结束都要重跑 `npm test` 核对没有回归）。
- 测试不得调用真实 agent（不运行 `claude`、`codex`、`gemini`，不请求 DeepSeek）。
- 提交由用户决定：实现期间不执行 `git commit`、`git add`、`git push`。
- 用户可见的错误信息和代码注释用中文，写成可读的中文，不转义。

**Interfaces:**
- Consumes: `runProcess`（含 `onChunk`）、`toRunResult`、`trackOutput`（引擎层）；`createSession`、`Session.send`（引擎层）。
- Produces:
  - `runProcess({ ..., signal?: AbortSignal })`：`signal` 触发后终止子进程树，立即 resolve `{ code: null, stdout, stderr, timedOut: false, cancelled: true }`；`signal` 在调用时已经触发则不启动进程，直接返回同样的结果（`stdout`、`stderr` 为空串）。
  - `toRunResult({ code, stderr, timedOut, cancelled? }, text, errorMessage)`：`cancelled` 为真时 `ok: false`、`error: '已取消'`；返回对象的字段集合不变。
  - 各适配器 `run({ ..., signal? })` 和 `dispatchTask({ ..., signal? })`：取消时返回 `{ ok: false, error: '已取消', ... }`。
  - `Session.cancel(): boolean`：有运行中的流程则中断它并返回 `true`，否则返回 `false`。
  - `Session.isRunning(): boolean`

- [ ] **Step 3: 改 process.js**

`runProcess` 的签名与开头改为：
```js
export function runProcess({ command, cwd, env, input = '', timeoutMs, onChunk, signal }) {
  return new Promise((resolve, reject) => {
    // 取消信号在启动前就已触发：不启动进程。
    if (signal?.aborted) {
      resolve({ code: null, stdout: '', stderr: '', timedOut: false, cancelled: true });
      return;
    }
    const child = spawn(command, { cwd, env, shell: true, stdio: ['pipe', 'pipe', 'pipe'] });
```
在 `const timer = setTimeout(...)` 之后、`child.stdout.setEncoding` 之前加入：
```js
    // 取消：连同子进程树一起结束，不等 close（被杀的进程可能仍占着管道）。
    const onAbort = () => {
      clearTimeout(timer);
      killTree(child);
      resolve({ code: null, stdout, stderr, timedOut: false, cancelled: true });
    };
    signal?.addEventListener('abort', onAbort, { once: true });
```
并在原有的 `child.on('error', ...)` 与 `child.on('close', ...)` 回调的第一行（`clearTimeout(timer);` 旁）各加一行 `signal?.removeEventListener('abort', onAbort);`。超时分支里也在 `killTree(child);` 前加同样一行。

`toRunResult` 改为：
```js
export function toRunResult({ code, stderr, timedOut, cancelled = false }, text, errorMessage) {
  const ok = !cancelled && !timedOut && code === 0 && !errorMessage;
  let error = errorMessage;
  if (!error && cancelled) error = '已取消';
  if (!error && timedOut) error = '执行超时，已终止';
  if (!error && code !== 0) error = `退出码 ${code}`;
  return { ok, text: ok ? text : '', exitCode: code, timedOut, error: ok ? undefined : error, stderr: stderr.trim() };
}
```

    setRunning(value) {
      running = value;

    send: async (text) => {

    requestPause: () => {

      calls.cancel += 1;
      return running;

// 在随机端口启动一个只用于测试的服务。allowedHosts 在监听之后才知道端口，所以用闭包延迟取值。
export async function start(session, options = {}) {
  const root = options.root ?? (await mkdtemp(join(tmpdir(), 'agentteam-server-')));
  let hosts = null;
  const app = createApp({ session, root, allowedHosts: () => hosts, ...options });
  const server = createServer(app);
  await new Promise((resolve) => server.listen(0, '127.0.0.1', resolve));
  const { port } = server.address();
  hosts = new Set([`127.0.0.1:${port}`, `localhost:${port}`]);
  return {
    root,
    port,
    base: `http://127.0.0.1:${port}`,
    close: () =>
      new Promise((resolve) => {
        server.closeAllConnections?.();
        server.close(resolve);
      }),
  };
}

// 不经过 fetch 的原始请求：可以自定义 Host、Origin，也不会对路径做规范化。
export function rawRequest({ port, method = 'GET', path = '/', headers = {}, body }) {
  return new Promise((resolve, reject) => {
    const req = request({ host: '127.0.0.1', port, method, path, headers }, (res) => {
      const chunks = [];
      res.on('data', (chunk) => chunks.push(chunk));
      res.on('end', () => {
        const text = Buffer.concat(chunks).toString('utf8');
        let json = null;
        try {
          json = JSON.parse(text);
        } catch {
          // 不是 JSON
        }
        resolve({ status: res.statusCode, headers: res.headers, text, json });
      });
    });
    req.on('error', reject);
    req.end(body);
  });
}

const MAX_BODY = 64 * 1024;

export class HttpError extends Error {
  constructor(status, message) {
    super(message);
    this.name = 'HttpError';
    this.status = status;
  }
}

export function sendJson(res, status, body) {
  const text = JSON.stringify(body);
  res.writeHead(status, {
    'Content-Type': 'application/json; charset=utf-8',
    'Content-Length': Buffer.byteLength(text),
    'Cache-Control': 'no-store',
  });
  res.end(text);
}

// 读取 JSON 对象请求体。空请求体视为 {}；超过上限、不是 JSON 对象都抛 HttpError。
export async function readJson(req, limit = MAX_BODY) {
  const chunks = [];
  let size = 0;
  for await (const chunk of req) {
    size += chunk.length;
    if (size > limit) throw new HttpError(413, '请求体过大');
    chunks.push(chunk);
  }
  const text = Buffer.concat(chunks).toString('utf8');
  if (!text.trim()) return {};
  let value;
  try {
    value = JSON.parse(text);
  } catch {
    throw new HttpError(400, '请求体必须是 JSON 对象');
  }
  if (!value || typeof value !== 'object' || Array.isArray(value)) {
    throw new HttpError(400, '请求体必须是 JSON 对象');
  }
  return value;
}

// 本机服务也要防网页偷调：浏览器里任何网页都能向 127.0.0.1 发请求，
// 而这个服务能指挥带编辑权限的 agent。所以 Host 必须是本机地址，带 Origin 时也必须是本机页面。
// allowedHosts 为 null 表示不校验（只用于没有监听端口的单元测试）。返回拒绝原因，通过返回 null。
export function checkRequest(req, allowedHosts) {
  if (!allowedHosts) return null;
  const host = req.headers.host;
  if (!host || !allowedHosts.has(host)) return '不允许的 Host';
  const origin = req.headers.origin;
  if (origin !== undefined) {
    const local = origin.startsWith('http://') && allowedHosts.has(origin.slice('http://'.length));
    if (!local) return '不允许的 Origin';
  }
  return null;
}

```js
import { ROLES, assignRole, checkEffort, checkModel, resolveAssignments } from '@agentteam/core/assign';
import { getAgent } from '@agentteam/core/agents';
import { HttpError, readJson, sendJson } from './http-util.js';
import { checkRequest } from './guard.js';

const MAX_TEXT = 20000;

export function createApp({
  session,
  root,
  credentialsFile,
  allowedHosts = () => null,
  staticHandler = null,
  heartbeatMs = 15000,
}) {
  // 先校验整批，全部合法才写入，避免前几项已写入、后面某项失败的半成品状态。
  async function putRoles(req, res) {
    if (session.isRunning()) throw new HttpError(409, '流程运行中，不能修改角色分配');
    const body = await readJson(req);
    const entries = Object.entries(body.assignments ?? {});
    if (entries.length === 0) throw new HttpError(400, 'assignments 不能为空');
    const checked = [];
    for (const [role, value] of entries) {
      try {
        if (!ROLES.includes(role)) throw new Error(`未知角色：${role}`);
        const agent = getAgent(value?.agent);
        const model = checkModel(value?.model ?? null);
        const effort = checkEffort(agent.id, value?.effort ?? null);
        checked.push([role, agent.id, model, effort]);
      } catch (err) {
        throw new HttpError(400, err.message);
      }
    }
    for (const [role, agentId, model, effort] of checked) {
      await assignRole(root, role, agentId, model, effort);
    }
    return sendJson(res, 200, await resolveAssignments(root));
  }

  async function postMessage(req, res) {
    const body = await readJson(req);
    const text = typeof body.text === 'string' ? body.text.trim() : '';
    if (!text) throw new HttpError(400, 'text 不能为空');
    if (text.length > MAX_TEXT) throw new HttpError(400, `text 过长（上限 ${MAX_TEXT} 字）`);
    if (session.isRunning()) throw new HttpError(409, '已有流程在运行，请等它完成，或先请求暂停');
    // 运行可能持续几分钟：立即返回 202，进度与结果经事件流送达。
    // 出错时 Session 已经发出收尾事件，这里只需要防止未处理的 Promise 拒绝。
    session.send(text).catch(() => {});
    return sendJson(res, 202, { accepted: true });
  }

  return async function handle(req, res) {
    try {
      const denied = checkRequest(req, allowedHosts());
      if (denied) return sendJson(res, 403, { error: denied });

      const url = new URL(req.url, 'http://local');
      switch (`${req.method} ${url.pathname}`) {
        case 'GET /api/state':
          return sendJson(res, 200, await session.state());
        case 'GET /api/roles':
          return sendJson(res, 200, await resolveAssignments(root));
        case 'PUT /api/roles':
          return await putRoles(req, res);
        case 'POST /api/message':
          return await postMessage(req, res);
        case 'POST /api/pause':
          if (!session.isRunning()) throw new HttpError(409, '没有运行中的流程');
          return sendJson(res, 200, { first: session.requestPause() });
        case 'POST /api/cancel':
          if (!session.cancel()) throw new HttpError(409, '没有运行中的流程');
          return sendJson(res, 200, { cancelled: true });
        default:
      }

      if (url.pathname.startsWith('/api/')) throw new HttpError(404, '接口不存在');
      if (staticHandler && req.method === 'GET') return await staticHandler(req, res, url);
      throw new HttpError(404, '未找到');
    } catch (err) {
      if (res.headersSent) {
        res.end();
        return;
      }
      if (err instanceof HttpError) return sendJson(res, err.status, { error: err.message });
      // 只记录错误信息，不记录请求内容（可能含 API key）。
      console.error('服务内部错误：', err.message);
      return sendJson(res, 500, { error: '服务内部错误' });
    }
  };
}

**Files:**
- Create: `packages/server/src/sse.js`、`packages/server/test/events.test.js`
- Modify: `packages/server/src/app.js`

**Interfaces:**
- Consumes: `session.log`（`createEventLog` 的返回值：`after(seq)`、`subscribe(listener) → unsubscribe`、`lastSeq`）。
- Produces:
  - `serveEvents(req, res, log, { heartbeatMs? }): boolean`：`after` 参数（查询串 `after`，或请求头 `Last-Event-ID`）不是非负整数时返回 `false`，且此时未写入任何响应；否则写出 `200 text/event-stream`，先补发 `seq > after` 的历史事件，再推送实时事件，返回 `true`。

`packages/server/src/sse.js`：

// SSE 事件流：先补发 seq 大于 after 的历史事件，再推送实时事件。
// 补发和订阅都在同一个同步片段里完成，期间不会有事件插进来，所以既没有空洞也不会重复；
// 仍用 last 去重，是为了让这个保证不依赖调用方的实现细节。
export function serveEvents(req, res, log, { heartbeatMs = 15000 } = {}) {
  const url = new URL(req.url, 'http://local');
  const raw = url.searchParams.get('after') ?? req.headers['last-event-id'] ?? '0';
  if (!/^\d+$/.test(raw)) return false;
  const after = Number(raw);

  res.writeHead(200, {
    'Content-Type': 'text/event-stream; charset=utf-8',
    'Cache-Control': 'no-store',
    Connection: 'keep-alive',
    'X-Accel-Buffering': 'no',
  });
  res.write(': ok\n\n');

  let last = after;
  const send = (event) => {
    if (event.seq <= last) return;
    last = event.seq;
    res.write(`id: ${event.seq}\ndata: ${JSON.stringify(event)}\n\n`);
  };

  const unsubscribe = log.subscribe(send);
  for (const event of log.after(after)) send(event);

  const heartbeat = setInterval(() => res.write(': ping\n\n'), heartbeatMs);
  heartbeat.unref?.();
  req.on('close', () => {
    clearInterval(heartbeat);
    unsubscribe();
  });
  return true;
}
```

import { AGENTS, getAgent } from '@agentteam/core/agents';
import { isAuthenticated, loadCredentials, saveAgentCredential } from '@agentteam/core/credentials';
import { HttpError } from './http-util.js';

// 给界面用的 agent 列表。只含"能选什么"和"是否已认证"，不含任何凭证内容。
export async function listAgents(credentialsFile) {
  const credentials = await loadCredentials(credentialsFile);
  return AGENTS.map((agent) => ({
    id: agent.id,
    name: agent.name,
    kind: agent.kind,
    models: agent.models ?? [],
    efforts: agent.efforts ?? [],
    authenticated: isAuthenticated(agent, credentials.agents[agent.id]),
  }));
}

// 保存认证。错误信息一律用固定文案，不回显请求内容（apiKey 不能进入响应或日志）。
export async function saveAuth(agentId, body, credentialsFile) {
  let agent;
  try {
    agent = getAgent(agentId);
  } catch {
    throw new HttpError(404, `未知 agent：${agentId}`);
  }
  const now = new Date().toISOString();

  if (body.method === 'api') {
    const usesKey = agent.kind === 'api' || (agent.apiKeyEnv?.length ?? 0) > 0;
    if (!usesKey) throw new HttpError(400, `${agent.name} 不使用 API key`);
    const key = typeof body.apiKey === 'string' ? body.apiKey.trim() : '';
    if (!key || key.length > 512 || /\s/.test(key)) throw new HttpError(400, 'apiKey 不合法');
    await saveAgentCredential(agent.id, { method: 'api', apiKey: key, savedAt: now }, credentialsFile);
  } else if (body.method === 'confirm') {
    // 订阅登录需要终端交互，无法经 HTTP 完成；这里只记录"用户已经在终端登录过"。
    if (agent.kind === 'api') throw new HttpError(400, `${agent.name} 只能使用 API key`);
    await saveAgentCredential(agent.id, { method: 'subscription', loggedInAt: now }, credentialsFile);
  } else {
    throw new HttpError(400, "method 必须是 'api' 或 'confirm'");
  }
  return { agent: agent.id, authenticated: true };
}

import { readFile, stat } from 'node:fs/promises';
import { extname, join, resolve, sep } from 'node:path';

const TYPES = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript; charset=utf-8',
  '.css': 'text/css; charset=utf-8',
  '.json': 'application/json; charset=utf-8',
  '.map': 'application/json; charset=utf-8',
  '.svg': 'image/svg+xml',
  '.png': 'image/png',
  '.ico': 'image/x-icon',
};

function notFound(res) {
  res.writeHead(404, { 'Content-Type': 'text/plain; charset=utf-8' });
  res.end('未找到');
}

export function createStaticHandler(webDir) {
  const base = resolve(webDir);
  return async function serveStatic(req, res, url) {
    let relative;
    try {
      relative = decodeURIComponent(url.pathname);
    } catch {
      return notFound(res);
    }
    let file = resolve(join(base, relative));
    // 解码和规范化之后仍必须在 web 目录之内。
    if (file !== base && !file.startsWith(base + sep)) return notFound(res);

    let info = await stat(file).catch(() => null);
    if (info?.isDirectory()) {
      file = join(file, 'index.html');
      info = await stat(file).catch(() => null);
    }
    if (!info?.isFile()) {
      // 单页应用：不带扩展名的未知路径交给前端路由；带扩展名的缺失资源是真的 404。
      if (extname(relative)) return notFound(res);
      file = join(base, 'index.html');
      info = await stat(file).catch(() => null);
      if (!info?.isFile()) return notFound(res);
    }
    const body = await readFile(file);
    res.writeHead(200, {
      'Content-Type': TYPES[extname(file)] ?? 'application/octet-stream',
      'Content-Length': body.length,
      'Cache-Control': 'no-cache',
    });
    res.end(body);
  };
}

import { createServer } from 'node:http';
import { existsSync } from 'node:fs';
import { createSession } from '@agentteam/core/session';
import { createApp } from './app.js';
import { createStaticHandler } from './static.js';

export const DEFAULT_PORT = 4317;
const LOOPBACK = new Set(['127.0.0.1', 'localhost', '::1']);

export async function startServer({
  root,
  port = DEFAULT_PORT,
  host = '127.0.0.1',
  credentialsFile,
  webDir = null,
  session = null,
}) {
  if (!LOOPBACK.has(host)) {
    throw new Error('开放远程访问前需要先实现访问令牌（见 docs/backlog.md B-002），当前只允许监听本机地址');
  }
  const activeSession = session ?? (await createSession({ root }));

  let hosts = null;
  const app = createApp({
    session: activeSession,
    root,
    credentialsFile,
    allowedHosts: () => hosts,
    staticHandler: webDir && existsSync(webDir) ? createStaticHandler(webDir) : null,
  });
  const server = createServer(app);

  await new Promise((resolve, reject) => {
    server.once('error', (err) => {
      reject(err.code === 'EADDRINUSE' ? new Error(`端口 ${port} 已被占用，请用 --port 换一个`) : err);
    });
    server.listen(port, host, resolve);
  });

  const actual = server.address().port;
  hosts = new Set([`127.0.0.1:${actual}`, `localhost:${actual}`, `[::1]:${actual}`]);
  const shown = host === '::1' ? '[::1]' : host;

  return {
    url: `http://${shown}:${actual}`,
    port: actual,
    session: activeSession,
    close: () =>
      new Promise((resolve) => {
        server.closeAllConnections?.();
        server.close(resolve);
      }),
  };
}

import { statSync } from 'node:fs';
import { resolve } from 'node:path';
import { DEFAULT_PORT } from './serve.js';

function directory(value, flag) {
  if (!value) throw new Error(`${flag} 需要一个目录`);
  const path = resolve(value);
  let ok = false;
  try {
    ok = statSync(path).isDirectory();
  } catch {
    // 不存在
  }
  if (!ok) throw new Error(`${flag} 指向的目录不存在：${path}`);
  return path;
}

export function parseArgs(argv) {
  const options = { root: process.cwd(), port: DEFAULT_PORT, webDir: null };
  for (let i = 0; i < argv.length; i++) {
    const flag = argv[i];
    if (flag === '--root') options.root = directory(argv[++i], '--root');
    else if (flag === '--web') options.webDir = directory(argv[++i], '--web');
    else if (flag === '--port') {
      const value = argv[++i];
      const port = Number(value);
      if (!value || !Number.isInteger(port) || port < 0 || port > 65535) {
        throw new Error('--port 必须是 0 到 65535 的整数');
      }
      options.port = port;
    } else throw new Error(`未知参数：${flag}`);
  }
  return options;
}
